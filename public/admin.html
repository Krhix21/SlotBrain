Cada número de respuesta pertenece a una empresa

Cada empresa conecta su propio número de WhatsApp. Al guardarlo, el token queda cifrado en la base y nunca vuelve a mostrarse. El mapa de entorno META_TOKENS_JSON sigue como primera opción de respaldo. Registra el número con su código de país, sin el +.

Conectar número de WhatsApp

Paso a paso · 5 minutos

FASE 1 — Modo PRUEBA (piloto): el número es el de la app de Meta y solo le escriben los 5 destinatarios verificados. Pega su phone_number_id + token permanente y listo (WABA ID déjalo vacío).

FASE 2 — Conectar número REAL (producción): el dueño compra una SIM exclusiva para el bot → el número se registra desde la app de Meta (el dueño recibe el código SMS y lo dicta) → token permanente del usuario del sistema → aquí se completan teléfono + phone_number_id + WABA ID + token. Servicios, profesionales y citas NO se tocan: solo cambia la conexión.

Antes de guardar, Probar conexión valida el token contra Meta; el token queda cifrado y nunca vuelve a mostrarse.

Solo puede haber UNA empresa usando el número de prueba a la vez.

De usuario del sistema, PERMANENTE (no el temporal de 24 h), con permisos whatsapp_business_management y whatsapp_business_messaging. Queda cifrado en el servidor.

Si la prueba sale bien, el número real se llena solo.
